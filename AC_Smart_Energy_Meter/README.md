# Software-Based AC Smart Energy Meter

Features:
- Simulated AC voltage/current waveforms
- RMS voltage and current, frequency, real/apparent/reactive power and power factor
- Synthetic energy and cost estimates
- Random Forest NILM classification (OFF, LED, FAN, MULTIPLE)
- Isolation Forest anomaly detection
- Rule-based simulated tamper detection
- Streamlit dashboard

## Important limitation
This is a software simulation. It does not measure a real electrical supply. Tamper indicators are synthetic digital events and cannot establish actual physical tampering. Do not use the project for billing, safety decisions, or real-world theft accusations.

## Run locally (Windows PowerShell)
Open a terminal in the project root:

```powershell
python -m pip install -r requirements.txt
python Python/generate_ac_data.py
python Python/train_models.py
python -m streamlit run Dashboard/app.py
```

Open the local URL shown by Streamlit (usually http://localhost:8501).

## Deploy on Streamlit Community Cloud
1. Push the entire repository to GitHub, keeping the folders as shown.
2. Open https://share.streamlit.io/ and sign in with GitHub.
3. Select the repository and branch.
4. Set the app file path to `Dashboard/app.py`.
5. Deploy. The public app URL will be generated by Streamlit Community Cloud.

The generated datasets and model files are included so the dashboard can start without running the training scripts again. You can regenerate them using the commands above.
